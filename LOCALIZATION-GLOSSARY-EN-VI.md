## Intentionally retained in English

- **Abyss Adventure**, Phi Nguyễn, character/class names, map/location/territory names, named gear/items/materials, named skills/signatures/abilities, bosses/enemies, and canonical mechanics.
- Familiar RPG terms where natural: Boss, Raid, PvP, PvE, DPS, Tank, Buff, Debuff, Crit, HP, MP, ATK, and DEF.
- Platform and technical identifiers such as Android, iOS, EN, VI, SHA-256, version strings, build numbers, URLs, source code, and hashes.

## Translation rule

Translate interface actions, navigation, explanations, accessibility labels, release instructions, and generic status text. Canonical names may appear unchanged inside Vietnamese sentences. Ambiguous or newly named game terminology requires Phi's approval before the glossary is changed.

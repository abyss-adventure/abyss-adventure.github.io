# Abyss Adventure

## Product truth
A free public storytelling website for Abyss Adventure, a collaborative dark-fantasy dungeon RPG project by Phi Nguyễn and Henry Parker. Phi Nguyễn is credited with the original game concept and creative direction; Henry Parker created the official website and is a project collaborator. The website introduces the world and its connected systems, then offers the current Android Open Beta through GitHub Releases. iOS is Coming Soon; no public IPA is approved.

## Audience and action
First-time visitors, primarily on phones, who want to understand the world and decide whether to try the Android Open Beta. English and Vietnamese share one site; canonical fantasy names remain English. The primary action is Download for Android.

## Established world
Original game artwork is authoritative: subterranean ruins, worn iron, dark stone, cold light. This is an extension of that visual identity, not a new brand. Use real images and gameplay captures; never label a promotional composition gameplay.

## Experience
Native scrolling creates a descent: title/camera push, ten-map exploration, base and advanced classes, evolution paths, beginner guide, equipment, connected systems, authentic current browser captures, creator credits, final download. Desktop has restrained depth; mobile uses shorter scenes and touch controls. Reduced motion keeps every story beat visible. Sound is opt-in.

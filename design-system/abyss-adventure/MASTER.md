# Abyss Adventure — implemented design system

The generic UI/UX Pro Max search suggested immersive interaction but also vibrant blocks and generic green accents. Those style suggestions are explicitly overridden by the user's pinned brief and real game art.

- Canvas: #080c0d; secondary #0d1213 / #101311.
- Primary text: #e7e3d9; secondary #a6b1ad; accent #c4ad79.
- Source world: ancient, cold subterranean environments; pixel characters and equipment remain visually authentic.
- Display: Alegreya 400. Reading/control text: Be Vietnam Pro 400/500. Self-hosted Latin/Vietnamese subsets.
- Layout: cinematic full scenes, an open editorial creator passage, large isolated character portraits, equipment inspection, real gameplay captures. Cards are not the page scaffold.
- Motion: native scroll with one GSAP architecture; title camera push, source-to-world masked reveal, small portrait drift. Short sticky regions; no scrolljacking.
- Mobile: shorter scenes, stacked composition, touch selection, horizontal system selector; no hover-only information.
- Reduced motion: static story, no parallax/title zoom, all scenes available.
- Primary action: weathered brass Download for Android; visibly labelled Preview Build.

See DESIGN.md for final built-world documentation and reports/DIRECTION.md for the narrative contract.
